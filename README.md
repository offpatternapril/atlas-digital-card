# atlas-digital-card
## Генератор личных визиток

`python3 make_card.py card.json [папка]` собирает визитку человека из `index.html` и небольшого JSON (см. `card.example.json`). Результат: папка с `index.html` и `mascot.webp`, ничего никуда не загружается.

Правила: данные берутся только у владельца визитки и с его согласия (`"consent": true` обязателен); только https-ссылки; тексты по языкам ru/pl/uk/be/en, недостающие берутся из русского. QR по-прежнему строится внешним сервисом `api.qrserver.com` (в него уходит адрес, на который ведёт QR).
